# Intoduction-to-AI

Pacman Solver

This project implements classical Artificial Intelligence techniques in the Pacman environment, focusing on both pathfinding and multi-agent decision making.

Phase A focused on single-agent search problems, where Pacman navigates mazes using algorithms such as Depth-First Search, Breadth-First Search, Uniform Cost Search, and A*. Heuristic functions were developed to improve efficiency and reduce the number of explored states.

Phase B extended the project to adversarial settings with ghosts, implementing Reflex Agents, Minimax, Alpha-Beta Pruning, and Expectimax to model competitive and probabilistic behavior. Custom evaluation functions were designed to guide decision making and improve overall game performance.
